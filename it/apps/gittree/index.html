Vedi chiaro nel tuo repository. GitTree è un client Git desktop veloce e open source per la cronologia visiva, le operazioni esplicite e la gestione dei repository in locale.

Lavora direttamente sul repository locale ed esegue vere operazioni Git, quindi resta compatibile con i flussi di lavoro e gli strumenti che usi già. Non serve un account, non c’è telemetria e non viene caricato niente da nessuna parte.

Funzioni

Repository e branch

  • Più repository in schede, con importazione ricorsiva delle cartelle, rilevamento dei worktree e link gittree:// dedicati
  • Navigatore dei branch con cartelle locali e remote, ricerca immediata e conteggio dei commit avanti e indietro
  • Crea, rinomina, elimina, traccia e fai il checkout dei branch, anche in un worktree collegato; recupera qualsiasi commit dal reflog

Cronologia

  • Grafo dei commit a più corsie, con i veri genitori e i merge octopus
  • Cronologia virtualizzata e a pagine, veloce anche sui repository grandi
  • Diff con evidenziazione per parola

Modifiche

  • Stage e unstage per file o per hunk, scarto delle modifiche, commit, amend, sign-off, firma GPG e SSH, hook
  • Merge, rebase e cherry-pick con anteprima, e un editor dei conflitti con i riquadri in arrivo, attuale e risultato
  • Stash, tag, remote e submodule dalla barra laterale e dalle impostazioni

Hosting e comodità

  • Revisione delle pull request per GitHub e GitLab (accesso con un codice dispositivo) e Azure DevOps (token di accesso personale), con commenti in linea e bozze cifrate
  • Link di confronto e di pull request per GitHub, GitLab, Bitbucket Cloud e Azure DevOps
  • Temi chiaro e scuro in cinque toni ciascuno, e scorciatoie da tastiera per fetch, pull, push e nuovo branch

Privacy e sicurezza

  • Nessun account GitTree e nessuna telemetria integrata
  • Niente caricato in automatico
  • I token di accesso restano nel processo principale, cifrati con l’archivio sicuro del sistema
  • Le operazioni Git vengono validate ed eseguite una alla volta per repository, e le modifiche sono protette da uno snapshot

Installazione

Scarica l’installer per il tuo sistema dalla pagina della release più recente. Finché non ci saranno i certificati di produzione, il sistema potrebbe avvisare che la build non è firmata.

Download per piattaforma
PiattaformaScarica
WindowsInstaller (.exe)
macOSImmagine disco (.dmg) per Apple silicon e Intel
LinuxAppImage, pacchetto Debian o pacchetto pacman

Su Arch Linux e derivate:

sudo pacman -U GitTree-*-linux-x64.pacman

Dai sorgenti

Servono Node.js 22 o successivo, Git e npm:

git clone https://github.com/giannoccarol/gittree.git
cd gittree
npm ci
npm start
