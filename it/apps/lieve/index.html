Un editor di codice leggero e nativo, senza Electron. È di casa su KDE Plasma e a suo agio su GNOME e sugli altri desktop, con l’aspetto, le icone dei file e le principali scorciatoie da tastiera di VS Code.

Fa poche cose e le fa bene. Lieve, come dice il nome, è leggero.

Quanto è leggero

Misurato con lo stesso progetto Angular di medie dimensioni aperto in entrambi gli editor:

Lieve e VS Code a confronto
VS Code, con le sue estensioniLieve
Memoria (PSS)circa 1.270 MBcirca 110 MB
Processi e thread24 e 4342 e 14
Spazio su discocirca 2,7 GBcirca 1,4 MB, più le librerie KDE che Plasma ha già

Si avvia in circa un quarto di secondo, e ogni progetto aperto in più costa pochi MB. Un language server, quando lo installi, costa quanto in VS Code.

Funzioni

Modifica

  • L’editor di Kate (KTextEditor): evidenziazione per centinaia di linguaggi, cursori multipli, .editorconfig
  • Editor affiancati, anteprima Markdown
  • I file non salvati restano dopo un riavvio o un crash, come in VS Code

Orientarsi

  • Explorer, e cerca e sostituisci nei file con ripgrep, che rispetta .gitignore
  • Quick Open (Ctrl+P) e la Command Palette (Ctrl+Shift+P)
  • Più progetti aperti insieme, una finestra ciascuno, con la scelta del progetto su Ctrl+R

Git

  • Pannello Git con i segni delle modifiche accanto ai numeri di riga e blame in linea
  • Branch, stash, cronologia e conflitti di merge

Strumenti

  • Terminale nel pannello: Konsole se è installato, altrimenti quello di Lieve
  • Prettier ed ESLint al salvataggio, un pannello Problemi e gli script npm
  • Vai alla definizione, errori e completamento da un language server, quando è installato

Installazione

Linux

Lieve ha bisogno di KDE Frameworks 6 (le librerie, non Plasma) e di ripgrep. Su Arch e CachyOS con Plasma quasi tutto è già installato, e Debian 13, Ubuntu 25.04 e Fedora hanno tutto. Questo script scarica l’ultima versione, la compila e la installa in ~/.local, senza sudo, e ti dice quali pacchetti mancano:

curl -fsSL https://raw.githubusercontent.com/giannoccarol/lieve/main/install.sh | bash

Oppure compilalo tu:

git clone https://github.com/giannoccarol/lieve.git
cd lieve
make -j$(nproc)
make install

I PKGBUILD per Arch sono in packaging/aur.

Windows

Scarica Lieve-v0.1.6-windows-x64.zip dalla release, decomprimilo dove vuoi ed esegui lieve.exe (Windows 10 o 11 a 64 bit, ripgrep incluso). Installa Git for Windows per le funzioni Git e Node.js per Prettier, ESLint e i language server.

Aggiornamenti

Lieve controlla da solo su GitHub se ci sono nuove versioni e propone l’aggiornamento nella barra di stato: un clic per installarlo, uno per riavviare.
