Apps and tools

Written for these ports, all open source.

  • Arco

    Camera app for the Lumia 950 XL: arc dials for white balance, focus, ISO, shutter and exposure, JPEG and DNG, video, optional multi-frame RAW processing on the GPU.

    Kotlin, Camera2, Jetpack Compose

  • ROM Bench

    Hardware test bench for custom ROM bring-up: automatic and guided checks, with reports ready for XDA, bug trackers and AI agents. Android 11 to 17.

    Kotlin, Jetpack Compose

  • cityman-iris

    Iris Unlock for the Lumia 950 XL on Android 16: recognition engine, face AIDL HAL and a capture tool for the IR camera.

    C++

  • Lumia 950 XL installer

    Installs the Android 16 ROM from Windows 10 Mobile, over another Android or as an update, checking every file and asking before every destructive step.

    PowerShell, Windows

  • Lumia 1520 and 930 installer

    Backs up the phone, extracts the stock firmware, sets up the BootShim and lk1st boot chain and the Android partitions, then installs the ROM.

    Python, Windows and Linux

  • CitymanParts and LumiaParts

    Device settings: performance profiles on the 950 XL; performance profiles, double tap to wake and capacitive keys on the 1520 and 930.

    Java
